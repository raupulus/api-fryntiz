Sobre el Proyecto

En este proyecto utilizo sensores de entrada analógica para una monitorización constante de consumo energético.

El objetivo es controlar cuanto están consumiendo los equipos subiendo estos datos a mi API y poder mejorar la gestión de energía principalmente para realizar tareas más pesadas en algunos dispositivos (y por lo tanto de más consumo) en momentos dónde tengo más energía almacenada/generada mediante placas solares y posponer otras tareas poco relevante.

Utilizo una pantalla con ahorro de energía implementado para apagarse tras un periodo de inactividad reactivándose al pulsar de nuevo el botón.

Hardware

Microcontrolador Raspberry Pi Pico W
Pantalla ST7735 1.8 SPI 128x160
Sensor de intensidad ACS712
Sensor de voltaje MAX471
ADC extra de 4 canales ADS1115
