Sobre el Proyecto

El objetivo de este proyecto es generar una "idea" basada en un sistema de roles con el que posteriormente terminar de generar un prompt mediante GPT3.5 Instruct.

Este prompt se utilizará para generar un lote/colección de imágenes mediante la API Stable Diffusion autoalojado en mis servidores aunque también he implementado poder utilizar Dall-e.

Una vez generado un lote de imágenes se subirán a mi propia API para ser almacenadas como galería. Puedes ver esta galería en la siguiente web de mi autoría https://aidyslexic.raupulus.dev

Posteriormente, las imágenes se publicarán en las redes sociales integradas. Hasta el momento: Twitter, Instagram, Mastodon y Telegram

Luego, con todas esas imágenes y utilizando la herramienta de video ffmpeg, se crea automáticamente un slideshow con transiciones entre imágenes y música de fondo.

Este video se subirá automáticamente a tiktok con selenium y Youtube utilizando su API. También se sincronizará enviando una petición a mi api para que el video se establezca como portada de colección/galería dentro de la web.

Estado Actual del proyecto

El proyecto está considerado completo abarcando los objetivos planteados.

Actualmente encuentro varios problemas que no solucionaré por considerarlos una inversión de tiempo sin recompensa, principalmente son la publicación en tiktok e instagram que al no ofrecer api para desarrolladores (o solo dar acceso a grandes creadores) me obligan a realizar una inversión de tiempo demasiado grande para renovar sesiones y evadir bloqueos por lo que esta funcionalidad queda implementada pero no se publica habitualmente.

Para el resto de redes si que continua trabajando pero a menor velocidad, es decir, solo trabaja cuando mis servidores tienen muy poca demanda y a un ritmo lento para no interferir.

Utilizo una raspberry pi 5 como cerebro para crear los slideshow en 4k y se encarga de ejecutar todos los programas desde generar el prompt hasta tener las imágenes y vídeos publicados pero la AI Stable diffusion la tengo en varios servidores de trabajo los cuales solo responden/generan imágenes cuando la saturación del servidor es menor a un 15% de recursos y solo ocupando un 50% de los recursos totales para no interferir con otras tareas.

En estos momentos al ser un proyecto experimental como hobby y no enfocarlo a obtener ingresos el ritmo de publicaciones es bastante bajo o con pausas intermitentes.
