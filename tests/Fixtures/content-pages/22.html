KeyCounter Display - Un gadget con Raspberry Pi Pico, servidor Websockets y micropython.

Para el proyecto del contador de pulsaciones he utilizado una pantalla junto a una Raspberry Pi Pico creando un servidor websockets en ella conectando desde cada equipo que se conecte como cliente.

Presentación Proyecto KeyCounter Display - Raspberry Pi Pico con servidor Websockets y Pantalla

Está programado en micropython y utiliza detección de ip local a través de mi API informando a esta de la dirección de red que ocupa en cada momento (para permitir desplazarla de ubicación) sincronizándose así con los ordenadores que conectan al websocket como clientes.

Las estadísticas se van actualizando en la pantalla a medida que voy pulsando teclas generando una gráfica con el progreso de las pulsaciones en base a la velocidad media de escritura.

En el caso de utilizar varios equipos se reemplaza esta gráfica por las estadísticas del segundo equipo.

También implemento función de ahorrar energía para apagarse tras 5 minutos de inactividad (realmente reduce el brillo/retroiluminación al 10-20%)
