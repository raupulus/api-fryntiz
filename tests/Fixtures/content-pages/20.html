Objetivo

En este proyecto utilizo un esp32 d1 mini para capturar los datos emitidos por una estación meteorológica bresser usando un módulo cc1101.

Añado unos leds para indicar lecturas erróneas y un juego de luces simulando relámpagos aleatorios cuando la lectura (y subida a mi API) se ha realizado correctamente para que visualmente se compruebe que funciona correctamente.

Estos datos capturados son subidos a mi propia API dónde he creado unos componentes (Vue 3) para mostrar los datos que han ido subiéndose al backend (laravel + Postgresql).

Hardware

Esp32 D1 Mini
Módulo RF a 868mhz (CC1101)
Leds
