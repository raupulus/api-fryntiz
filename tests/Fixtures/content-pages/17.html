Sobre el Proyecto

Este proyecto consta de un conjunto de scripts para tener un entorno funcional con el que desarrollar en poco tiempo de forma automatizada y además tenersincronizada la configuración de distintos equipos/dispositivos con los que trabajo.

Esta herramienta prepara completamente el entorno de programación, aplicaciones,servidores, comandos personalizados, interfaz gráfica, plantillas, repositorios... en Debian y MacOS principalmente pues son los que suelo utilizar a menudo aunque añado soporte parcial para Fedora, Rasbian/RaspberryOS, Gentoo.

Todas las configuraciones y elecciones se han establecido a mi gusto pero lo comparto conlicencia GPLv3 para que sea utilizado o aprovechado por cualquiera que guste.

Algunos Objetivos

Se plantea lo más modular que me ha sido posible para que en algunos casos nosea necesario ejecutar el script completo y solo la parte que realmentenecesitas (si fuese el caso).

Configurar terminales, bash y zsh
Instalar tipografías
Instalar editores con sus personalizaciones
Instalar IDEs
Configurar sistema y variables globales
Ampliar repositorios desde fuentes estables y fiables
Instalar configuraciones y personalizaciones para el sistema y programas enel HOME del usuario
Instalar atajos y personalizaciones para trabajar con git, GitHub y GitLab
Instalar servidores como Apache2, PostgreSQL, MariaDB
Instalar lenguajes de programación, dependencias y librerías para → php,python, nodejs, ruby, bash....
Instalar Navegadores WEB para desarrolladores como Firefox Developer yFirefox Nightly
Instalar herramientas para ayudar a debug en lenguajes web
Configurar interfaces gráficas
