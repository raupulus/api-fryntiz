Este es un proyecto con el que monitorizo los campos electromagnéticos mediante un sensor para detectar rayos estimando la distancia desde el punto de origen hacia el sensor y su energía.

Esto me resulta útil para poder almacenarlo en mi api de meteorología como parte de los datos climáticos recopilados y a su vez actuar sobre otros dispositivos más críticos apagándolos cuando se intensifica una tormenta que genere demasiados rayos evitando daños en esos equipos.

Hardware

Pantalla SSD1306 de 128x64px
Sensor de rayos CJMCUAS3935
Raspberry pi pico w
3 Leds
Batería reciclada de vaper (650mah)
Módulo de carga

Raspberry Pi Pico W

Este microcontrolador es el cerebro para todo el proyecto.

Con el monitorizo en un hilo constante recibiendo una interrupción (IRQ) en el momento que el sensor detecta un rayo, lo almaceno y cada pocos segundos actualizo la información en mi backend api.

Detección de Rayos con el Sensor CJMCU AS3935

El sensor CJMCU AS3935 es un dispositivo diseñado para detectar la proximidad de rayos mediante la captura de las características únicas de los pulsos electromagnéticos generados por las descargas eléctricas durante una tormenta.

Pantalla SSD1306

Utilizo una pantalla SSD1306 en la que ver que haencendido correctamente y además mostrará información del último rayo detectado.
