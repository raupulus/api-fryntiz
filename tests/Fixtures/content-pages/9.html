Sobre el Proyecto

Este proyecto es simplemente decorativo aún teniendo una posibilidad remota de conseguir resolver un bloque.

Se trata de un gadget que intenta resolver bloques para ganar la recompensa de BTC.

He diseñado un soporte y adaptado el diseño original de la caja para permitir mejor ventilación e incorporar una batería de un vaper desechable evitando cortes mientras lo desplazo de un lugar a otro manteniendo una autonomía de pocas horas.

Software

Se utiliza el programa original de Nerd Miner para funcionar.

Sobre este software para el esp32 he añadido una sincronización de datos hacia una api propia dónde voy recogiendo las estadísticas cada un minuto lo que me permite monitorizar estos datos en la barra de tareas de mi escritorio y en otras pantallas.
