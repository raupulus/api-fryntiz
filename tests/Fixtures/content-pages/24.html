Este proyecto tiene como objetivo proporcionar una forma visual de monitorear los precios de criptomonedas en tiempo real, utilizando una Raspberry Pi Pico W con la capacidad de mostrar la información en una pantalla de 8 dígitos basada en el MAX7219.

El código está desarrollado en MicroPython y se conecta a la red para obtener los precios actualizados de las criptomonedas, que luego se visualizan en la pantalla.

El proyecto también incluye un codificador rotatorio (encoder) para permitir la navegación o ajuste de parámetros (como la criptomoneda a monitorizar).

Hardware

Raspberry Pi Pico W.
Pantalla de 8 dígitos de 7 segmentos (con chip MAX7219).
Codificador rotatorio (encoder).
Interruptor
2 pulsadores
