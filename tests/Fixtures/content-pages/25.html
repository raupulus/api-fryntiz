Sobre el proyecto

Este Proyecto de gadget lo utilizo para monitorizar la calidaddel aire en mi oficina de casa mostrando por pantalla los valores.

Los datos mostrados son:

Temperatura
Humedad
Presión
Calidad del aire
CO2 ppm
tVOC ppb
Luz
UV
Ruido ambiente

Funcionamiento

El funcionamiento es el siguiente:

Se realiza una lectura de todos los sensores
Los valores actuales son actualizados para mostrarse en la pantalla
Si ha pasado más de un minuto, se subirá a la api en caso de tener el wificonfigurado y la api habilitada en las variables de entorno
Se hace una pequeña pausa y vuelta a empezar.
